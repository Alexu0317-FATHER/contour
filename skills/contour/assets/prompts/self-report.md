# 跨端自述 prompt

把下面分隔线之间的内容原样发给任意一个 AI 端（ChatGPT / Codex / Claude.ai / Claude Desktop / Claude Code），把它的回答完整存回来。

**这份是基线倾倒用的**，端首次纳入时跑。日常增量用 `self-report-incremental.md`。

设计说明（不要连这段一起发）：

- 「记得 / 现推」的区分是必须的。模型分不清"存储里的记忆"和"从这次对话现场推出来的印象"，混在一起会污染整份档案，冲突消解也没法做。
- **要求保留原话**，尤其是指令类和偏好类。用户原话"别他妈跟我绕"和模型转述的"用户偏好直接的沟通风格"，信息量差一个量级，而后者根本没法用来写 `routing.md` 的线索列。
- 明确点名要负面的、被否决的、关于沟通方式的内容。不点名的话，模型会自动产出一份得体的正面小传，而档案里最值钱的恰恰是被磨平的那些。
- **实体名起头**是为了下游去重：同一个项目在五个端各留了一堆碎片，实体名开头才能机械对齐。
- **第 7 类（落在会话之外的产出物）要单独点名**，混在第 2 类里收不上来。这一类的特殊之处是：它的位置**只有产出它的那一端知道**，别的端不可能自己推出来，也没有任何机制会让它传过去。同时问"改过什么"是因为资产路由最隐蔽的腐烂方式就是——指针还对、页面还在、内容早已超出记录的覆盖范围。
- 结尾那句"倒完了没"是关键的一问。它承认导出可能不完整，把这个信息显式要出来，于是能追问、能分页。**答"还有更多"就再跑一轮**，别默认第一轮就是全部。
- 结尾禁止总结陈词，是因为模型习惯用一段升华收尾，那段是纯生成物，会被下游误当成结论。

---

我要把你对我的记忆导出，用来建一份跨平台的个人档案。请按下面的要求输出，这是一次数据导出，不是一次对话。

**只列你真的存着的东西。** 每一条都标来源：

- `[记]` = 来自你的长期记忆 / 自定义指令 / 项目文件，跨会话存在的
- `[推]` = 你从当前这次对话现场推断的，之前并不知道

不确定是哪种，标 `[推]`。宁可少记也不要把推断当记忆——这份档案会被好几个 AI 反复使用，一条错的会一路复利下去。

**尽可能保留我的原话。** 涉及我给你的指令、我的偏好、我对你的纠正时，一字不差地引用我当时说的话，别转述、别润色成书面语。

**知道时间就写上**（"2025 年初"、"三个月前"这种模糊的也行，不用凑成精确日期）。完全不知道就写 `[unknown]`，不要留空、不要猜。

**涉及具体实体的条目，用实体名起头**（项目、人、工具、公司）。同一个项目尽量合成一条。

按下面六类分开列，每类下面用 `-` 开头一条一行：

1. **身份与事实** —— 职业、家庭、居住、健康、技能、在用的工具
2. **正在进行的事** —— 项目、目标、进度、当前卡在哪
3. **判断方式** —— 怎么做决定、看重什么、什么标准下会说不
4. **明确的负面项** —— 讨厌什么、否决过什么方案（**连否决的理由一起写**）、什么话题会让情绪起来、什么是"不是我"的
5. **沟通偏好** —— 希望被怎么说话、纠正过你什么（**原话**）、什么场合要直接什么场合要先接情绪
6. **零散的、你不确定要不要记的** —— 顺口提过一次的、看起来跟主线无关的。**这一类不要省略**，它往往是最有价值的
7. **你为我产出过、并且落在这次会话之外的东西** —— 文档、指南、脚本、配置、模板。分两种都要写：
   - **你创建的**：写清楚它是什么、**存到了哪里**（平台 + 库 / 目录 / 文件名）、大概什么时候
   - **你改过的**：本来就存在、后来你往里补过或改过的，写清楚补了哪部分
   只在会话里回答过、没有落地成文件的**不算**，别把普通回答凑进来

要求：

- 不要美化。负面的、尴尬的、自相矛盾的照原样写。一份只有优点的档案是没用的。
- 不要合并同类项、不要概括。宁可琐碎。
- 不知道的类别就写"无"，不要凑。
- 整份导出放进**一个代码块**里，方便我整段复制。
- **列完直接停。不要写总结、不要写感想、不要在结尾加一段升华。**
- 代码块之后，单独回答一句：这是你存着的全部，还是还有更多没列出来？
