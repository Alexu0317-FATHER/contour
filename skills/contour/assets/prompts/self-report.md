# 基线自述 prompt

记忆存储首次纳入、需要由某个端自述时使用；能直接读取记忆文件或官方导出时不必自述。日常同步使用 `self-report-incremental.md`。将分隔线后的提示用于能访问该存储的端，保留其完整回答及实际采集范围。

---

导出你当前能提供的、关于我的记忆，以及能够确认的外部知识资产动作，供知界整理。

前六类每条先标来源，再标是否推断：

- 来源，三选一：
  - `[记:<类型>]`：来自可跨会话访问的记忆或资料，类型写原生记忆、自定义指令、项目文件或其他具体材料。
  - `[会话]`：来自当前对话中我的陈述或我提供的材料。
  - `[来源不明]`：你知道这条内容，但无法确认它来自哪里。只写不明，不猜测来源，也不因此把它当作推断。
- 推断：条目是你根据上述来源推断出的结论时，另加 `[推]` 并写出依据；直接来自记录或我的陈述的不加。

已加载的知界材料单独注明，不将其当作新的独立来源。

涉及我的指令、偏好和沟通纠正时，能核对原话就保留原话；只能概括时明确标为转述，不编造引文。

记录条目的时间和来源；仅知道大致时间就如实写大致范围，无法确定时写 `[unknown]`。涉及项目、人物、工具或公司时，以实体名开头，保持同一实体命名一致。

按以下类别逐条列出：

1. **身份与事实**：职业、家庭、居住、健康、技能和工具。
2. **正在进行的事**：目标、进度和当前困难。
3. **判断方式**：决策依据、价值取舍和拒绝条件。
4. **明确否决与负向约束**：拒绝的做法、不认同的标签及原因。
5. **沟通偏好**：期望的回应方式、纠正和适用情境。
6. **其他可能有复用价值的信息**：尚未归类的记忆及其不确定性。
7. **已保存的可复用知识资产**：文档、指南、模板，以及明确作为跨任务资料保存的脚本或配置。记录创建或修改动作、名称、位置、时间和变化范围。

第七类标 `[操作]`（当前会话或工具记录可核对）或 `[记]`（仅由跨会话记忆召回），不收仅靠推断认为存在的资产。普通项目实现、代码修改和由当前工作区管理的交付物不登记为知识资产。

输出要求：

- 中性保留事实、否决、矛盾与不确定项，不用概括性评价替代具体条目。
- 没有可提供内容时注明“无可访问内容”或“无法确认”，不填补推断。
- 选用能完整转存的形式：在聊天中交给我复制时，把全部条目放在一个代码块内；直接写入文件或通过工具提交时，按该通道要求的格式写入。不附加人物总结。
- 条目之后说明：本次已列出当前可访问内容，还是仍有可以继续提供的内容。不要宣称已完整导出无法观察的后台记忆。
