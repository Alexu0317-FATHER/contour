# 知界 Contour

[English](README.md) | 中文

> 让不同 AI 逐渐认识同一个你。

如果你同时使用网页端和本地端的AI（例如ChatGPT/Codex）来执行不同的任务，或者仅仅是为了有效利用两端的独立用量，这时候可能就会产生交叉：你在Codex上提到用ChatGPT做过的调研，Codex却完全没有这部分的记忆；

又或者你自己都忘了几个月前到底是用Chatgpt还是Claude写了一篇文章，你只能分别在两端分别搜索一次；

甚至，你想用 Claude 为你的项目写一个营销页面，因为这里有你的写作偏好，但是项目背景和讨论全积累在 Codex 里，你不得不花费额外用量向Claude再解释一遍Github没承载的项目讨论；

总之，只要你多端使用AI，每一个 AI 都会认识你的一部分，但换一个地方，你又得重新解释自己。

**知界的目标，就是把分散在各个AI端的用户记忆逐渐链接起来。**

它从不同 AI 当前能够提供的记忆以及你提供的资料中取得信息，整理成一份由你控制的统一档案，再把相关内容提供给其他 AI 使用。

![知界做什么](docs/images/what_contour_does_zh.png)

随着持续使用，不同 AI 对你的理解会逐渐趋同，而不是各自认识一个不同的你。

## 技能特性


- **个人信息的安全由你掌控** 知界，只是那个为各端记忆画出边界的技能，无论你为自己的记忆选择本地储存、Dropbox、Google Drive、Notion……只要AI有相关的技能进行读写就行。

- **害怕设置的麻烦。** 初始化的时候不用面对无数轮的问题，知界会让AI帮你完成。

- **利用AI自己的记忆系统**。  不管是Anthropic、OpenAI还是Google，他们都会不断优化记忆存取方式。知界打算充分利用他们的机制，只是让更全的记忆加载进来。


> 知界不要求所有 AI 保存完全相同的记忆。它关注的是：当你换一个 AI 时，它是否仍然能够理解与你当前问题有关的重要背景、偏好和沟通方式。

## 安装

想让哪几个 AI 互相认识你，就在哪几个 AI 里各装一次知界。

### Claude 网页端（claude.ai）/ Claude Desktop

1. 打开 **Customize → Plugins**，点右上角 **Add → Add marketplace**。
2. 选 **Add from a repository**，URL 填 `Alexu0317-FATHER/contour`，点 **Sync**。**Sync automatically** 保持打开，知界更新后会自动同步。
3. 同步完成后，在 **Plugins** 里找到 **contour** 并安装。

![打开 Add marketplace](docs/images/claude_add_plugins_01.png)

![选择 Add from a repository](docs/images/claude_add_plugins_02.png)

![填写仓库并同步](docs/images/claude_add_plugins_03.png)

### Claude Code

```text
/plugin marketplace add Alexu0317-FATHER/contour
/plugin install contour@contour
```

出现安装范围时选 **user scope**，在任何项目里都能用。装好后按提示重新加载插件，或者开一个新会话。

### Codex

```text
codex plugin marketplace add Alexu0317-FATHER/contour
codex plugin add contour@contour
```

装好后开一个新会话。

### ChatGPT 网页端

1. 下载 [contour.zip](https://github.com/Alexu0317-FATHER/contour/releases/latest/download/contour.zip)。
2. 在 ChatGPT 侧边栏打开 **插件**，切到 **技能**，点右上角 **＋**，选 **从电脑上传**，选中下载的 zip。

![ChatGPT 上传技能](docs/images/chatgpt_upload_skill.png)

### 让 AI 帮你装

Claude Code 和 Codex 能自己执行安装命令，把这句话发给它就行：

```text
帮我安装这个插件：https://github.com/Alexu0317-FATHER/contour
```

## 开始使用

知界要从至少两个不同的 AI 各取得一份记忆，才会整理出第一份档案。所以第一次使用分三步：

1. **在第一个 AI 里说：**

   ```text
   帮我开始使用知界。
   ```

   它会先问你档案存在哪里，并确认这个 AI 能读写那里，连不上会告诉你缺什么。位置定好后，再问清你还用哪些 AI、允许它读取哪些内容，然后取出这个 AI 对你的记忆。

2. **换到第二个 AI，说：**

   ```text
   把这里加入我现有的知界档案。
   ```

   它会先问档案在哪，连上后告诉你档案里已经接入了哪些 AI，再取出这个 AI 对你的记忆，和第一份一起整理成第一版档案。

3. **回到第一个 AI，说「同步知界」**，让它读取整理好的档案。

以后每接入一个新的 AI，在那里装好插件，重复第 2 步即可。

- 手上已有个人简介、画像文件或记忆导出，可以在第 1 步一起交给它。它会拿这些资料和各个 AI 的记忆对照，但资料本身不能顶替第二个 AI。
- 只做完第 1 步时，知界会先保存取得的内容，等第二个 AI 接入后再生成档案。

### 点名调用

AI 没有自动用上知界时，可以直接点名：

| | Claude（网页端 / Desktop / Claude Code） | Codex | ChatGPT |
|---|---|---|---|
| 知界（任何操作） | `/contour` | `$contour` | 输入 `@`，选 contour |
| 同步 | `/contour-sync` | `$contour-sync` | 输入 `@`，选 contour，接着写“同步” |
| 查看状态 | `/contour-status` | `$contour-status` | 输入 `@`，选 contour，接着写“查看状态” |

命令后面可以接一句话，比如 `/contour 这条信息过时了，以后别再用`。

## 日常使用

### 同步

```text
同步知界
```

在哪个 AI 里说，它就把自己最近新记住或更正的内容交给档案，整理后再读回最新版本。其他 AI 不用同时开着，下次用到哪个，在那边也说一声。第一次取出的记忆不一定全，之后每次同步会接着补。

目前同步由你发起。AI 在做别的事时注意到值得记下的新情况，可能会在事情做完后问你一句要不要同步。

每次同步结束，知界会用表格告诉你结果，例如：

**补进档案的内容**

| 来源 | 内容 |
|---|---|
| Claude Code | 开始做新项目 X，目标十月上线 |
| Claude Code | 更正：工作年限是 6 年，不是 5 年 |
| ChatGPT 网页端 | 没取到：连接已过期，需要重新连接 |

**需要你处理**

| 来源 | 问题 | 需要你做什么 |
|---|---|---|
| Claude Code / ChatGPT 网页端 | 居住城市一个记上海、一个记杭州，看不出哪个更新 | 告诉我以哪个为准 |

两个 AI 说法对不上、又看不出哪个更新时，知界不会替你选。汇报里还会列出哪些 AI 已经读到新档案、哪些还没读到。

### 查看状态、接着做完

```text
看下知界状态
```

只查看记录，不改动档案。上次同步断在半路（比如连接掉了），说「继续上次没完成的同步」，它会从断的地方接着做，已经处理过的内容不会重复处理。

### 更正或撤回

直接告诉 AI 哪里不对，或者哪条不要了：

```text
我之前说的工作经历有一处不对，以我刚才说的为准，更新知界。
```

```text
讨论方案时先指出会影响决定的前提，再给建议。把这个偏好记进知界。
```

```text
这条信息已经过时了，让知界以后别再用。
```

更正后，旧内容会标成已被取代，来龙去脉查得到。撤回后，知界不再在档案里使用这条内容，同时会告诉你：原始记录、档案的历史版本和各个 AI 自己的记忆里，可能还留着它。

### 检查几个 AI 的理解是否一致

```text
几个 AI 对我的理解好像不一样，帮我检查一下。
```

知界会拿同一批场景题分别测各个 AI，比较它们怎么回答。同步完成只说明各个 AI 拿到了同一份档案，它们是否真的照着档案理解你，要靠这项检查来看。

## 遇到问题

知界本身出错时（比如按步骤做不下去），AI 会先告诉你这次做完了什么、没做完什么，再起草一份不含个人内容的问题报告，问你要不要提交。你也可以直接到 [Issues](https://github.com/Alexu0317-FATHER/contour/issues) 反馈，请不要贴记忆原文或个人资料。

## 隐私

- 知界没有自己的服务器，不收集任何数据。你的档案只存在你自己选的位置。
- 读取哪些 AI 的记忆、档案写到哪里，都要先经过你同意；超出已同意的范围时会再问你。
- AI 读取记忆和档案时，内容会经过你正在使用的那家 AI 服务，按它自己的隐私条款处理。
- 知界不会向你索要密码、Cookie 或其他登录凭据。
- 出错时起草的问题报告会去掉个人内容，你同意后才会提交到公开的 GitHub Issues。
